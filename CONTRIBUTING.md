## Purpose

FORGE is a personal professional portfolio. Contributions are welcome when they improve clarity, accessibility, documentation accuracy, or fix genuine defects — not when they rebrand or fork the product narrative.

## Scope

In scope:

- documentation fixes
- accessibility improvements
- clear bug reports against the portfolio site
- small, well-described UX fixes

Out of scope:

- adding unrelated projects or self-promotion
- changing brand positioning without discussion
- introducing dependencies without justification
- requesting disclosure of private product source code

## How to contribute

1. Open an issue using the templates in `.github/ISSUE_TEMPLATE/`.
2. Fork only if you intend to propose a focused fix.
3. Keep changes small and reviewable.
4. Run `npm run lint` and `npm run build` before opening a PR.
5. Fill the pull request template.

## Decisions

- English is preferred for issues and PR descriptions targeting the public README/docs.
- Do not commit secrets, personal data dumps, or screenshots with sensitive content.
- Do not add CI badges or status claims that are not true for this repository.

## Limits

Maintainer may decline changes that conflict with brand, licensing, or portfolio strategy. There is no SLA for review timing.
